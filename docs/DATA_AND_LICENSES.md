# Datos, licencias y gates

El repositorio separa tres conceptos:

1. `technical_status`
2. `runtime_policy`
3. `legal_gate`

Que una API entregue HTTP 200 no equivale a permiso comercial.

Antes de promover una fuente a producción:
- confirmar endpoint;
- validar licencia;
- comprobar actualidad;
- ejecutar health monitoring;
- revisar schema;
- definir atribución;
- definir fallback.

La licencia MIT del repositorio no relicencia los datos de terceros.
