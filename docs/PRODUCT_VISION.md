# Product Vision — Landfinder Chile

## Posicionamiento
**Encuentra, analiza y compara terrenos con inteligencia territorial.**

Landfinder no busca competir inicialmente como portal inmobiliario masivo.
El producto se posiciona como una capa de inteligencia sobre el territorio.

## Usuario inicial
- consultoras;
- entidades patrocinantes;
- constructoras;
- inmobiliarias;
- arquitectura / ingeniería;
- corredores especializados;
- analistas territoriales.

## Problema
La evaluación preliminar de un terreno exige revisar fuentes fragmentadas,
mapas, proyectos futuros, conectividad, servicios y restricciones.

## Propuesta
Un mapa único que permite:
1. seleccionar varias áreas;
2. activar múltiples capas;
3. distinguir construido vs futuro;
4. comparar zonas;
5. guardar evidencia;
6. monitorear cambios.

## Principio UX
El mapa es el producto.
Perfil, alertas, proyectos y reportes existen para convertir el mapa en un
flujo de trabajo recurrente.
